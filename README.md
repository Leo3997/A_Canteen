# 智慧食堂 (Smart Canteen System)

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Python](https://img.shields.io/badge/Python-3.8+-green.svg)](https://www.python.org/)
[![React](https://img.shields.io/badge/React-18.0+-61DAFB.svg)](https://reactjs.org/)

智慧食堂是一个结合了 **计算机视觉 (CV)** 与 **人工智能 (AI)** 的次世代餐饮管理系统。它通过 **YOLOv8** 的快速检测与 **SAM (Segment Anything Model)** 的精准分割，实现了食堂自动结算与剩菜率的量化分析，有效解决传统食堂结算效率低、厨余浪费难以统计的痛点。

---

## 🌟 核心愿景

**"看到，识别，分析。"**
传统食堂依赖人工收银或昂贵的 RFID 芯片碗碟。本系统利用标准 RGB 摄像头，实现：

- **秒级识别**：瞬间识别餐盘内的各类菜品。
- **精准量化**：通过像素级分割，计算每道菜的剩余比率。
- **数据驱动**：为食堂经营者提供直观的浪费统计与菜品受欢迎程度分析。

---

## 🚀 核心功能

### 1. 智能图像处理

- **餐盘校正 (`calibrate_plate`)**：自动识别餐盘角落，利用透视变换将倾斜的餐盘校正为标准视图。
- **环境自适应**：具备 Laplacian 梯度检测，过滤模糊或反光严重的无效抓拍。

### 2. AI 识别引擎

- **YOLOv8 检测**：快速定位菜品名称（如：红烧肉、青菜、米饭等）。
- **SAM 精准分割**：对检测到的区域进行抠图，计算菜品所占像素面积，实现剩菜率的精确计算。

### 3. 数据大屏与管理

- **实时看板**：可视化显示当前就餐人数、平均剩菜率、识别准确率。
- **口味偏好趋势**：柱状图及雷达图展示菜品受欢迎程度，辅助食堂优化菜单。
- **AI 经营建议**：集成大语言模型，根据识别数据提供采购与备餐优化策略。

## 🛠️ 技术架构

### 后端 (Edge/Server)

- **核心框架**: [FastAPI](https://fastapi.tiangolo.com/) (高性能异步 Python API)
- **视觉库**: OpenCV, PyTorch, Ultralytics (YOLOv8), Segment Anything Model
- **数据库**: SQLite (通过 SQLAlchemy ORM)
- **报告生成**: Pandas & Openpyxl (导出 Excel 分析报告)

### 前端 (Web Dashboard)

- **框架**: React + Vite
- **UI 组件**: TailwindCSS + [Shadcn UI](https://ui.shadcn.com/)
- **图表**: Recharts
- **动效**: Framer Motion & ReactBits

## 📦 快速上手

### 1. 环境准备

确保已安装 Python 3.8+ 和 Node.js。

### 2. 后端安装

```bash
# 进入后端目录
cd backend
# 安装依赖
pip install -r ../requirements.txt
# 启动服务器
python ../run_server.py
```

### 3. 前端安装

```bash
# 进入前端目录
cd frontend
# 安装依赖
npm install --legacy-peer-deps
# 运行开发环境
npm run dev
```

### 4. 数据初始化

运行 `optimize_indexes.py` 以确保数据库索引性能最优。
